# BootNexa identity

**Product:** BootNexa  
**Tagline:** Bootable drives. Made simple.  
**Product category:** Bootable-media workstation / disk utility  
**Voice:** Clear, technically precise, calm when operations are dangerous.

## Mark

The BootNexa symbol pairs a USB connector with an electrical bolt and a partial boot ring. It remains legible at favicon size and avoids relying on the letters "BN" in the icon. Source artwork is `public/logo.svg`. The repository header illustration is `assets/bootnexa-banner.svg`.

## Usage

Keep clear space equal to one quarter of the symbol width. Do not rotate or recolour the artwork casually; do not place it over detailed photography. Prefer the full wordmark in headings and the SVG icon in navigation, install packages and favicons. The README screenshot must come from the running application, not a fabricated success state.

## Naming diligence

The name and logo are project branding proposals; trademark, domain, and marketplace conflicts must be cleared before a commercial launch.
